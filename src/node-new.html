노드 정의

초기 status는 draft. DataPoint 5건 검증 후 live 전환 가능.

depth ≤ 2 제약. 3차 이상은 사일로가 흩어집니다.
시도 무관이면 테마 허브 또는 정보형 페이지가 됩니다.
https://example.com/tutoring/seoul/seocho-gu/ url(node) = "/" + theme_path(node.theme) + "/" + region_path(node.region) + "/"
검증된(verified) 작성자만 선택 가능. 작성자 관리 →
10개 섹션 구조. 3·4·5번이 데이터 게이트 대상.
발행 게이트 대상 — 작성되지 않으면 live 전환 불가.

사전 검증

DB 트리거가 실제 INSERT 시점에 한 번 더 검사합니다.

✓

✓

✓
depth 정합 node depth = parent depth + 1 = 2
✓

✓
